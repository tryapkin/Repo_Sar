# Погодная станция

ESP32 + датчик BME280 (температура, влажность, давление). Данные выводятся на дисплей и отправляются по Wi-Fi.

- [ ] 4. Отправка данных по Wi-Fi (MQTT)
- [ ] 5. Дисплей
