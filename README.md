# ART MAR — artmar.am

Сайт компании ART MAR: поставка электронных компонентов и промышленного оборудования
(лазерное сканирование, насосы, воздушные компрессоры, гироскопические инклинометры).

## Стек

- Статический одностраничный сайт, собранный в **Mobirise v5.8.0** (Bootstrap 5, jQuery, Mobirise-расширения).
- Сборки и зависимостей нет: это готовые HTML/CSS/JS-файлы, которые выгружаются на хостинг как есть.
- Хостинг Apache: `.htaccess` перенаправляет http на https.

## Структура

| Путь | Что это |
|---|---|
| `index.html`, `assets/` | Армянская версия (главная) |
| `en/index.html`, `en/assets/` | Английская версия |
| `ru/index.html`, `ru/assets/` | Русская версия |
| `.htaccess` | Редирект на https |

Каждая языковая версия несёт свою полную копию `assets/` (так экспортирует Mobirise).

## Запуск локально

```sh
python3 -m http.server 8000
```

Затем открыть http://localhost:8000/ (армянская версия), `/en/` или `/ru/`.

## Форма обратной связи

Форма работает через сервис Mobirise Formoid: адрес получателя зашифрован в скрытом поле
`data-form-email`. При ручной правке HTML это поле нужно сохранить, иначе заявки перестанут приходить.
